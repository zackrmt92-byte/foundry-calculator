# ⚔️ Foundry Strategy & Calculator

A lightweight, web-based tool designed to calculate resources and plan team rosters for the Foundry event.

🚀 **Live App:** [https://zackrmt92-byte.github.io/foundry-calculator/](https://zackrmt92-byte.github.io/foundry-calculator/)

---

## ✨ Features

* **Foundry Calculator:** Calculate points and estimations.
* **Team Roster & Strategy Builder:**
  * Assign Team Leaders and Joiners with custom notes.
  * Map teams directly to key event targets (Imperial Foundry, Prototype Sites, Facilities, etc.).
* **One-Click Export:**
  * 📋 Copy clean formatted text directly into Discord or game chat.
  * 📸 Export high-resolution PNG summary images to share with your alliance/state.

---

## 🛠️ Built With

* HTML5 / CSS3
* JavaScript (ES6)
* [html2canvas](https://html2canvas.hertzen.com/) for image generation
